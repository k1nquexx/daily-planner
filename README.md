# 🚀 DayFlow — Умный планировщик задач и итогов дня

Кроссплатформенное приложение (ПК + Смартфон) с мгновенной двусторонней синхронизацией, защитой по PIN-коду и глубокой аналитикой дня.

---

## ⚡ Быстрый старт

### Способ 1: Запуск готового приложения (Один клик)
Просто запустите файл:
```bat
start.bat
```
Приложение автоматически откроется в браузере по адресу: **`http://localhost:8080`**

* **PIN-код по умолчанию:** `1234` (можно сменить в любой момент по иконке ключа в шапке).

---

## 📱 Как подключить и установить на смартфон

1. Убедитесь, что ваш компьютер и телефон подключены к **одной Wi-Fi сети**.
2. В приложении на ПК в правом верхнем углу нажмите кнопку **«Телефон»**.
3. На экране появится **QR-код** и прямая ссылка (например: `http://192.168.0.37:8080`).
4. Наведите камеру телефона на QR-код и откройте страницу.
5. **Установка на экран телефона (PWA):**
   * **iOS (Safari):** Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх) ➔ **«На экран Домой»**.
   * **Android (Chrome):** Нажмите три точки в меню ➔ **«Добавить на главный экран»** (или «Установить приложение»).
6. Теперь DayFlow открывается на телефоне как отдельное нативное приложение с быстрым доступом!

## 🔄 Мгновенная синхронизация (ПК ⇄ Телефон)
* Реализована на **WebSockets (STOMP)**.
* Вы поставили галочку или добавили задачу на телефоне — **на мониторе ПК это меняется в ту же секунду** без обновления страницы, и наоборот.
* В шапке горит зеленый индикатор `🟢 Live Sync`.

## 🌟 Возможности и фичи («навороченнее обычных заметок»)

1. **Планирование дня (To-Do & Focus):**
   * Разделение приоритетов: 🔥 **Главный фокус**, ⚡ **Важно**, ☕ **Рутина**.
   * Интерактивные подзадачи (чеклисты внутри задачи).
   * Оценка времени на задачу (в минутах).
   * Категории: *Работа*, *Учеба*, *Спорт*, *Личное*, *Общее*.
   * Праздничное конфетти при завершении всех задач дня 🎉.

2. **Итоги дня и рефлексия (Daily Review):**
   * Слайдер настроения дня (😫 Тяжело ➔ 🚀 В огне).
   * Уровень энергии дня (🪫 ➔ 🔥 Максимум).
   * Поле **«Главные победы и результаты дня»**.
   * Поле **«Мысли, инсайты и выводы»** (свободный дневник).
   * Автоматическое сохранение при наборе текста.

3. **Умный перенос хвостов (Smart Rollover):**
   * Если вчера остались незавершенные дела, сверху появляется плашка: *«Остались задачи с прошлого дня (3). Перенести на сегодня?»* — в один клик.

4. **Аналитика и геймификация:**
   * **Стрики продуктивности (🔥 X дн.)**: считает серию непрерывных дней, когда вы закрывали задачи или вели дневник.
   * Процент выполнения плана дня в реальном времени.

5. **Безопасность:**
   * Spring Security + JWT авторизация.
   * Доступ защищен PIN-кодом (хэширование BCrypt в БД).
   * Блокировка сессии одной кнопкой.

## 🛠 Технологический стек

* **Бэкенд:** **Java 21 LTS** + **Spring Boot 3**
  * Spring Data JPA + Embedded H2 Database (хранится в `./data/plannerdb`, не требует установки СУБД).
  * Java 21 **Virtual Threads** (максимальная производительность при минимальном потреблении памяти).
  * Spring Security + JWT.
  * Spring WebSocket (STOMP message broker).
* **Фронтенд:** **React** + **Vite** + **Tailwind CSS** + **Lucide Icons**
  * PWA (Progressive Web App) манифест и мобильная адаптация под жесты и экраны смартфонов.
